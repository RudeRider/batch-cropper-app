Project Overview & Documentation

Welcome to Cloud Doc Studio — a professional Google Docs-style editor with direct GitHub repository publishing. Use the formatting ribbon above to style headings, tables, callouts, checklists, and code blocks.

Key Capabilities

  • Print-Ready Page Layout: Edit on a crisp A4/Letter canvas or switch to Dark Paper / Wide View anytime.
  • Direct GitHub Sync: Commit your documents as clean .md (Markdown), .html, or .txt files directly to any GitHub repository branch.
  • Multi-Document Notebooks: Switch between notebooks in the sidebar with automatic cloud & local persistence.
Tip: Click Save to GitHub in the top bar to push this document to your repository via the GitHub API or open it directly in the GitHub web editor.
